# Orçah — Reformulação completa da Home

## Objetivo

Reformular toda a comunicação da Home do Orçah para posicionar o produto não apenas como um "gerador de orçamento", mas como uma ferramenta simples para o prestador de serviço:

- criar orçamentos profissionais;
- enviar pelo WhatsApp;
- acompanhar visualização e resposta;
- apresentar serviços, produtos e trabalhos;
- ter uma página própria para divulgar na bio;
- receber pedidos de orçamento pela própria página.

A referência visual/estrutural analisada é o concorrente `fazerorcamento.com`, mas esta implementação deve ter **identidade própria**.

### Regra importante

Não copiar:

- textos;
- frases;
- imagens;
- ilustrações;
- identidade visual;
- estrutura gráfica distintiva;
- código;
- componentes visuais característicos.

Podemos aproveitar **princípios de UX, hierarquia, ordem de informações e lógica de conversão** que façam sentido para o Orçah.

# 1. POSICIONAMENTO

## Problema da Home atual

A mensagem atual começa com:

> Orçamento no WhatsApp.
> O cliente aprova no link.

Isso comunica bem uma funcionalidade, mas coloca o Orçah em uma posição muito estreita: parece inicialmente uma ferramenta para enviar orçamento pelo WhatsApp.

O grande diferencial do Orçah é maior:

> **O prestador pode ter seu próprio espaço profissional para apresentar o trabalho e transformar visitantes em pedidos de orçamento, além de criar e acompanhar os próprios orçamentos.**

A Home deve vender essa ideia desde o primeiro contato.

## Conceito central

**Seu trabalho. Sua página. Seus orçamentos.**

O Orçah deve parecer uma ferramenta feita para quem trabalha por conta própria e precisa apresentar o serviço, receber oportunidades e organizar os orçamentos sem complicação.

# 16. FAQ

## Perguntas frequentes

### Preciso de cartão para começar?

Não. O teste começa sem cartão.

### O cliente precisa instalar algum aplicativo?

Não. O cliente pode abrir a página e o orçamento pelo navegador do celular.

### Posso usar pelo celular?

Sim. O Orçah foi pensado para funcionar muito bem no celular.

### Posso colocar o link da minha página no Instagram?

Sim. Sua página pode ser usada como o link da bio e compartilhada também pelo WhatsApp e outras redes.

### Posso colocar fotos dos meus trabalhos?

Sim. Sua página pode apresentar seus trabalhos com fotos e informações.

### O cliente consegue pedir orçamento pela minha página?

Sim. A página possui uma ação para o visitante solicitar um orçamento.

### Posso enviar o orçamento pelo WhatsApp?

Sim. Você envia o link do orçamento diretamente para o cliente.

### O cliente consegue aprovar o orçamento?

Sim. O cliente pode abrir o orçamento e aprovar, recusar ou solicitar alteração.

### Preciso usar PDF?

Não. O link é o principal formato para o cliente abrir e responder. O PDF continua disponível quando você precisar.

### Posso cancelar quando quiser?

Sim.

### O Orçah serve para qual profissão?

Para dezenas de tipos de prestadores de serviço, com modelos adaptáveis ao ramo.

# 19. TOM DE VOZ

O texto deve ser:

- simples;
- direto;
- brasileiro;
- profissional sem ser corporativo;
- fácil para um pedreiro, pintor, marceneiro ou fotógrafo entender;
- orientado a benefício;
- sem juridiquês;
- sem linguagem excessivamente tecnológica;
- sem exageros.

Evitar:

- "revolucione seu negócio";
- "potencialize sua produtividade";
- "solução completa e inovadora";
- "ecossistema";
- "transformação digital";
- "gestão 360º";
- frases genéricas de SaaS.

Preferir:

> Mostre seu trabalho.

> Envie o orçamento.

> O cliente abre pelo celular.

> Saiba quando ele visualizou.

> Tenha sua página.

> Coloque o link na bio.

> Receba pedidos de orçamento.

# 20. IDENTIDADE VISUAL E CORES

A identidade atual do Orçah usa:

- azul-marinho escuro;
- amarelo/laranja como destaque;
- fundo cinza claro.

A direção não deve copiar o verde do concorrente.

Antes de alterar as cores, fazer uma auditoria visual.

## Objetivo

A paleta deve transmitir:

- confiança;
- profissionalismo;
- simplicidade;
- acessibilidade;
- energia;
- tecnologia sem parecer "startup genérica".

O laranja/amarelo pode continuar como cor de ação, especialmente em CTAs, mas deve existir uma hierarquia clara.

### Regra

Não usar laranja em excesso.

Usar a cor de destaque principalmente para:

- CTA;
- links de ação;
- elementos importantes;
- pequenos destaques;
- estados selecionados.

O azul-marinho deve continuar sustentando:

- textos principais;
- títulos;
- navegação;
- elementos de interface;
- percepção de confiança.

O background deve ficar mais leve e neutro.

# 22. PRINCIPAL MUDANÇA EM RELAÇÃO À HOME ATUAL

A Home atual começa vendendo:

> "Orçamento no WhatsApp."

A nova Home deve começar vendendo:

> **"Mostre seu trabalho. Envie o orçamento. Feche o serviço."**

Isso permite apresentar o Orçah como algo maior que um gerador de orçamento.

O produto passa a ser percebido como:

**Página profissional + captação de pedidos + orçamento + acompanhamento.**

# 23. INSTRUÇÕES PARA IMPLEMENTAÇÃO NO OPUS

Antes de alterar o código:

1. Leia a Home atual.
2. Leia os componentes utilizados pela Home.
3. Identifique a estrutura atual de responsividade.
4. Faça uma análise de quais componentes podem ser reaproveitados.
5. Não altere funcionalidades.
6. Não altere rotas existentes.
7. Não remova links funcionais.
8. Não invente funcionalidades que o produto ainda não possui.
9. Não invente números de usuários, avaliações, clientes ou resultados.
10. Não copie o concorrente.

Depois disso, implemente a nova hierarquia de conteúdo.

## Prioridade de implementação

### Fase 1

Hero + Header + página pública + orçamento.

### Fase 2

Como funciona + recursos.

### Fase 3

Profissões + preço + FAQ.

### Fase 4

CTA final + footer.
